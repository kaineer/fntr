# История проекта fntr

Краткий журнал реализованных шагов.

## 2026-10-16

### Каркас приложения
- Vite-проект: React + TypeScript
- Three.js через `@react-three/fiber`
- Redux Toolkit + `react-redux`
- Стартовая сцена с панелью и viewport

### Объекты на сцене
- Пустая сцена при старте (сетка для ориентира)
- Меню `Space` → Insert → Cube / Box / Sphere
- Слайс `objects`: массив объектов с `type`, `size`, `rotation` (+ позже `color`, `position`)

### Редактирование размеров
- Форма Ширина / Высота / Глубина для выбранного объекта
- Live-обновление геометрии при изменении инпутов
- ПКМ по инпуту: коэффициенты ×/÷ 3, 10, 33, 100; шаг для стрелок = значение после применения
- Форма поверх сцены, якорь над объектом; открытие через меню Size; Esc закрывает форму
- Фикс ПКМ-меню: portal в `document.body` (из‑за `transform` у оверлея)

### Взаимодействие с объектом
- Клик по объекту → Object-меню (без Insert): Size, Color, Rotate, Move, Align
- `Space` → Insert (+ пункты объекта, если есть выделение)
- Зум сцены колесиком мыши

### Цвет
- Поле `color` у объекта
- Меню Color с палитрой

### Поворот на 90°
- Rotate → локальная ось X/Y/Z → +90° / −90°
- Локальный поворот через кватернион (`rotateLocal90`)

### Перемещение
- Поле `position` у объекта
- Move → мировая плоскость XY / XZ / YZ → drag мышью
- Режим drag с баннером; Esc / «Готово» — выход

### Привязка углов
- Align → угол исходного объекта (`a: xyz` … `h: XYZ`) → клик по цели → угол цели
- Совмещение выбранных углов в мировом пространстве (перенос исходного объекта)

## 2026-10-19

### Поворот вокруг ребра
- Rotate: клик по ребру бокса, форма по Space (−90° / +90° / 180°)
- Shift+ЛКМ+движение: дискретный поворот ±90° вокруг выбранного ребра (форма по Space остаётся)
- Для группы: handles на всех выделенных боксах; ребро любого участника — ось для всей группы

### Палитра и вид сцены
- Цвета мебели: white / light gray / dark gray / black / brown; default — белый
- Светлый фон viewport и сетка (чтобы тёмные объекты читались)

### Вырезание / копирование / вставка
- Меню Delete или `X` — cut (в буфер и удаление)
- `Y` — yank, `P` — paste
- Paste сохраняет size / rotation / color; смещение по мировому AABB, без пересечения с исходником
- Буфер поддерживает несколько объектов и признак группы

### Управление камерой и выделением
- ЛКМ — выбор объекта; ПКМ — контекстное меню
- Орбита и zoom относительно центра выделения (центроид), иначе — начало сцены
- Фиксированный угол места камеры 20° к pivot
- Клик по пустому месту (без drag) сбрасывает Size / Rotate / Move / Align
- Синий outline у выделенных объектов

### Множественное выделение и группы
- Shift+ЛКМ добавляет к выделению; Shift+клик мимо объектов ничего не меняет
- `G` — создать группу (≥2 объекта); `Shift+G` — разгруппировать
- У объекта поле `groupId`; клик по участнику выделяет всю группу
- Совместные Move / Color / Rotate / Delete (и cut/yank/paste) для multi и групп
- Size и Align — только для одного объекта

### Align в сцене
- Align (только параллелепипед) → вершины на источнике → целевой бокс → вершина цели → совмещение и выход
- Отмена Esc / «Отмена» на любом шаге; меню углов убрано

### Insert
- Из меню Insert убран Box (достаточно Cube + Size)
